&ensp;&ensp;&ensp;&ensp;新建作业，端口新增的时候添加如下设置

<center><img src="/static/SCM/images/expand/ssh/ssh-6.3-0001.png" style="zoom: 100%;" /></center>

&ensp;&ensp;&ensp;&ensp;设置完成后，提交作业即可

<center><img src="/static/SCM/images/expand/ssh/ssh-6.3-0002.png" style="zoom: 100%;" /></center>

&ensp;&ensp;&ensp;&ensp;进入作业，设置ssh服务（如果没有ssh服务则需要进行安装）

<center><img src="/static/SCM/images/expand/ssh/ssh-6.3-0003.png" style="zoom: 100%;" /></center>

``` shell
  apt install openssh-server                 //安装ssh服务
  vim /etc/ssh/sshd_config  
  修改：PerminRootLogin yes
```
&ensp;&ensp;&ensp;&ensp;在作业中设置root用户密码，并使用以下命令重启ssh服务

``` shell
/etc/init.d/ssh restart						//重启ssh服务
```

&ensp;&ensp;&ensp;&ensp;使用ssh连接工具进行访问

<center><img src="/static/SCM/images/expand/ssh/ssh-6.3-0004.png" style="zoom: 100%;" /></center>

::: tip 温馨提示
  + 请注意自己作业的IP，使用下方ssh命令时，注意更换！！！
:::
