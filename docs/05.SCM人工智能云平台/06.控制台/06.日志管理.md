#### 日志管理

+ 登录日志
+ 操作日志

## 登录日志
&ensp;&ensp;&ensp;&ensp;点击日志管理--登录日志，可以查看用户的登录信息，包括：登录IP地址、登录状态、时间等；可以通过检索功能查找相匹配的信息




&ensp;&ensp;&ensp;&ensp;点击设备名称，进入当前存储，右侧弹出存储卷管理对话框

&ensp;&ensp;&ensp;&ensp;为了管理员方便排查登录日志，平台提供了针对用户、IP、状态、以及时间段进行检索的方式

<img src="/static/SCM/images/console/record/login_record/login_record-6.3-0001.png" alt="imageLibraries-01" style="zoom: 40%;" />

::: warning 温馨提示
  + 只可查询60天内的数据!!!
:::

## 操作日志


&ensp;&ensp;&ensp;&ensp;点击日志管理--操作日志，可以查看用户的操作信息，包括：使用的功能内容、接口调用时长、操作地址等；可以通过检索功能查找相匹配的信息

&ensp;&ensp;&ensp;&ensp;为了管理员方便排查操作日志，平台提供了针对操作人员、状态、以及时间段进行检索的方式

<img src="/static/SCM/images/console/record/operate_record/operate_record-6.3-0001.png" alt="imageLibraries-01" style="zoom: 40%;" />

::: warning 温馨提示
  + 只可查询30天内的数据!!!
:::
