# 产品介绍

&ensp;&ensp;&ensp;&ensp;迅思代码生成一体机是基于中科创达&思腾合力算力的新一代编码辅助工具，工具结合了中科创达&思腾合力积累多年的OS编程数据，涵盖Android、车载、IOT等场景。拥有补全迅速、推荐准确、可私有化部署、支持数据和功能定制等多重产品优势，可帮助企业实现“高效复用原有数据”的核心目标，从研发各流程提升效率，建立企业专属的编码工具。

## 核心场景

### 代码补全

&ensp;&ensp;&ensp;&ensp;迅思基于开源数据和创达积累的优质数据进行训练，因此迅思代码生成一体机可以通过分析当前代码的上下文语义环境，给出当前位置下一行或下一段可能的代码内容建议，减少用户的实际输入，提高研发效率。未来迅思代码生成一体机还会支持整个Codebase范围的语义分析，进一步提升代码建议的准确性。

### 代码生成

&ensp;&ensp;&ensp;&ensp;迅思代码生成一体机支持通过注释生成代码、对话生成代码、生成单元测试、生成代码注释、代码解释、对代码进行优化等多种维度的代码生成功能，另一方面提供了快捷的自定义提示词功能，能够让不同场景的用户都能有快捷高效的体验。旨在最大程度满足不同的研发场景需求，全方位提高研发效率。

### 技术问答

&ensp;&ensp;&ensp;&ensp;依托迅思代码生成一体机提供强大的技术问答能力，未来更是会支持包含本地Codebase、企业Wiki、互联网数据等多个来源的答案接入整合，让您的研发问题不需要离开IDE就能获得解决，打造沉浸式的开发体验。

### 产品优势

+ 快速而精准的代码补全：工程师使用占比最多的功能，创达内部80%+工程师都在使用，每月能为创达贡献20万行高质量代码，补全速度和准确性都处于业界Top水平。
+ 强大且方便的生成和问答：迅思代码生成一体机提供覆盖全方位研发场景的众多代码生成相关功能，并且提供了易于使用的快捷访问方式，同时还支持用户自定义功能，更利于专项适配不同的开发场景。
+ 支持全平台OS、主流IDE和众多编程语言：迅思代码生成一体机支持 Windows、macOS、Linux 三大操作系统、Visual Studio Code 和 JetBrains IDEs两大主流IDE平台以及50+种众多编程语言。
+ 企业级数据后台：迅思代码生成一体机提供详尽的数据分析功能，包括功能使用量、答案采纳量、采纳量按功能或语言分布等等，全方位可视化提效成果，助力个人与企业的提效与复盘。另一方面，我们还提供企业代码、企业数据接入管理的数据后台能力，让数据在流转中产生更多价值。
+ 支持私有化部署：迅思代码生成一体机提供涵盖私有云和私有硬件的全方位私有化部署服务以及详尽的技术支持，让您享受高效编码的同时无后顾之忧，全力保障公司信息安全。
+ 支持私有数据和功能定制：单纯的私有化部署无通常法满足企业数据复用和场景定制的需要，因此迅思代码生成一体机提供针对到场景的数据全流程处理服务和工具功能定制服务，您的需要就是我们的目标。
