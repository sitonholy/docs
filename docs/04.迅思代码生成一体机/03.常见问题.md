## Jetbrains IDE

### 1.JCEF运行环境缺失问题

#### 问题背景

&ensp;&ensp;&ensp;&ensp;JCEF是用于支持H5页面显示的一个运行框架，已经被内置到了Jetbrains的runtime中。

&ensp;&ensp;&ensp;&ensp;部分基于Jetbrains二次开发的IDE会把默认的runtime更换为不支持JCEF的runtime，典型案例为Android Studio。出现此问题时会在插件页面窗口显示如下提示信息：

<center><img src="/static/assets\images\qajb-1-1c04c995fc0c0a7fd02b6d17f06d06f4.PNG" alt="imageLibraries-01" style="zoom: 100%;" /></center>

#### 解决方法

    1. 点击Help菜单，选择Find Action选项

<center><img src="/static/assets\images\qajb-2-d242cd633ac9dfa6c909f4e20ac1d636.PNG" alt="imageLibraries-01" style="zoom: 60%;" /></center>

    2. 搜索‘runtime’关键字，选择‘Choose Boot Java Runtime for the IDE’选项

<center><img src="/static/assets\images\qajb-3-73ef763e4d553b9f0bb4c25ace5b34b5.PNG" alt="imageLibraries-01" style="zoom: 60%;" /></center>

    3. 选择‘with JCEF’的runtime进行安装

<center><img src="/static/assets\images\qajb-4-c178b0ab6908a04ac0384be1b60cca53.PNG" alt="imageLibraries-01" style="zoom: 60%;" /></center>
