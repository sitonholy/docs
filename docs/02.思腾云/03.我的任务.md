::: warning 温馨提示

+ 任务关机`48小时`后将`清空缓存盘中的数据`，请在关机前将`重要数据`存放到`共享/分布式/对象存储`中。

+ 任务关机`7天`后，将自动进行`释放`操作，请及时备份数据或者点击保存镜像进行保存(保存镜像不会保存缓存盘中的数据)。

+ 按量计费的`任务关机`后`运算卡`将会`释放`，再次开机时可能面临空闲`运算卡`不足`无法开机`的情况。

:::

| 名称 | 路径 | 读写模式 | 备注 |
| :----:| :----: | :----: | :----: | 
| 共享存储 | /root/siton-data-* | 读写 | 可以实现同一地区不同任务之间的文件同步共享 | 
| 对象存储 | /root/siton-object-* | 读写 | 可以实现同一地区不同任务之间的文件同步共享 | 
| 公开数据目录 | /root/siton-pub | 只读 | 公开数据目录 | 
| 缓存盘目录 | /root/siton-tmp | 读写 | 计算节点本地目录 |

## 提供的服务

::: warning 温馨提示
  + `思腾云`上提供的链接非长期有效链接，偶尔会因网络问题而变更，请留意通知。
:::
### SSH服务
&emsp;&emsp;任务状态由创建中变为运行中后，会生成SSH访问地址以及密码，

  + 复制SSH链接，本地打开终端/CMD/Shell，粘贴SSH链接
  + 回车后需要输入连接密码，在`我的任务`页面点击`复制密码`按钮，
  + 右键粘贴密码（密码在终端上不显示），再回车即可成功连接到任务

&emsp;&emsp;具体使用参考`教程与案例`中的`远程连接任务`操作

![wangpan-upload](/static/SitonCloud/images/my_task_ssh_copy.png)

### Jupyter服务

&emsp;&emsp;任务状态由创建中变为运行中后，会生成`Jupyter`的访问地址，具体使用参考`教程与案例`中的`Jupyter使用`操作

+ `Jupyter`的工作路径为`/root`

![wangpan-upload](/static/SitonCloud/images/my_task_service.png)
### VSCode服务

&emsp;&emsp;任务状态由创建中变为运行中后，会生成`VSCode`的访问地址，具体使用参考`教程与案例`中的`VSCode使用`操作

+ `VSCode`的工作路径为`/root`
  
![wangpan-upload](/static/SitonCloud/images/my_task_service.png)


### Tensorboard服务

&emsp;&emsp;任务状态由创建中变为运行中后，会生成`Tensorboard`的访问地址，具体使用参考`教程与案例`中的`Tensorboard使用`操作

+ `Tensorboard`的日志存放路径为`/root/tensorboard`

![wangpan-upload](/static/SitonCloud/images/my_task_service.png)

### 自定义服务

&emsp;&emsp;如果您希望使用自定义服务，请到`我的任务--便携工具--更多--自定义服务`点击打开，使用的端口，您请将自定义的服务以提示的端口启动，便可以通过此入口进行访问。
::: warning 温馨提示
  + 该链接非长期有效链接，偶尔会因网络问题而变更，请留意通知。
:::

### 无卡模式

&emsp;&emsp;当任务关机后，运算卡被其他用户占用时，用户可以启用无卡模式来操作任务中的数据。
::: tip 
+ 无卡模式配置为：1核心CPU，2GB内存，无运算卡卡，配置费用:￥0.10/时，最低消费￥0.01
:::
![wangpan-upload](/static/SitonCloud/images/no-gpu.png) 


### 保存镜像
&emsp;&emsp;目前`思腾云`上所有任务都支持保存当前环境的功能（包含机器中除网盘、缓存盘以外的所有文件变动）。

&emsp;&emsp;在租用运算卡的时候，我们可以选择为大家提供的基础镜像，在进行项目运行、调试的时候，大家可能会在基础镜像上进行修改，比如安装第三方python包、自己conda创建了新的虚拟环境、apt安装了其他系统工具等，默认释放机器时会直接清除所有机器环境。

&emsp;&emsp;如果您想保存这些修改，您可以在AI训练中心-我的任务中更多--保存镜像进行保存环境，保存成功后，下次租用时可以直接使用。
