## 将`conda`虚拟环境添加到`JupyterLab`内核

::: warning 温馨提示
+ 在`conda`中有多个虚拟环境，将其添加到`JupyterLab`中，便于在`JupyterLab`中切换环境。
:::

### 1、安装`nb_conda`扩展

```shell
conda activate base
conda install nb_conda
```

### 2、在`conda`中创建一个的虚拟环境

::: warning 温馨提示
+ 一定需要指定`python`版本，否则新环境与旧环境无法隔离
:::

```shell
conda create -n siton_env python=3.8  # siton_env：为自定义的环境名称
```

### 3、进入刚刚创建的虚拟环境

```shell
conda activate siton_env   # siton_env：为上一步创建conda环境使用的名称
```

### 4、安装ipykernel

```shell
pip install ipykernel -i https://pypi.tuna.tsinghua.edu.cn/simple # 用于在`JupyterLab`中添加内核，为了加快安装速度这里使用了清华的镜像源
```

### 5、将虚拟环境`siton_env`添加到`JupyterLab`中

```shell
python -m ipykernel install --user --name=siton_env
```
### 6、重启`JupyterLab`服务
```shell
supervisorctl restart jupyterlab
```
重启成功后，`conda`创建虚拟环境就会自动添加到`JupyterLab`内核中

### 5、检查是否安装成功
```shell
jupyter kernelspec list
```
