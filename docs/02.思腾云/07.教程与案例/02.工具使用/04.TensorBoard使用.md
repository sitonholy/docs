`TensorBoard`是用于提供机器学习工作流程期间所需的测量和可视化的工具。它使您能够跟踪实验指标，例如损失和准确性，可视化模型图，将嵌入物投影到较低维度的空间等等。

`思腾云`上启动的任务中，默认会开启`TensorBoard`服务，您可以在`便捷工具-更多`中找到。

![wangpan-upload](/static/SitonCloud/images/my_task_service.png)

::: warning 

+ 如果您不希望启用`TensorBoard`功能，请在任务状态为`运行中`时，使用`SSH`链接到任务中，执行如下命令

```shell
# 关闭tensorboard
supervisorctl stop tensorboard
```
:::
