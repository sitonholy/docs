## 一、简介

&ensp;&ensp;`Xftp`是基于`Windows`平台的功能强大的`SFTP`、`FTP`文件传输软件。使用`Xftp`以后，`windows`用户能安全的在`UNIX/LINUX`和W`indows PC`之间传输文件。

##  二、软件下载及安装

+ 1、安装

&ensp;&ensp;下载链接:[https://www.xshell.com/zh/free-for-home-school/](https://www.xshell.com/zh/free-for-home-school/)

![wangpan-upload](/static/SitonCloud/images/xftp/xftp_01.png)

&ensp;&ensp;点击下载后，会向您填写的邮箱中发送一个下载链接，下载即可。（如邮箱的收件箱中未找到下载邮件，可在邮箱中的垃圾邮件选项中查找）

+ 2、安装：安装过程是傻瓜式安装，自行选择安装位置就可以。

## 三、Xftp的使用

+ 1.获取任务SSH主机名、任务SSH端口号、任务密码

  + 1.1 打开思腾云控制台，复制登录指令和密码，然后粘贴到文本或编辑器中。

    ![WechatIMG615](/static/SitonCloud/images/pycharm/WechatIMG615.png)

  + 1.2 粘贴完成后如下所示

      + 登录指令：ssh -p 54717 root@219.150.35.115

      + 密码：8e7aBcV2V2 

&ensp;&ensp;命令拆解如下： 

    + 任务SSH主机名：219.150.35.115

    + 任务SSH端口号：54717 

    + 任务用户名：root 

    + 任务密码：8e7aBcV2V2

+ 2.连接成功后，接下来看到的，左边为windows，右边为Linux

![wangpan-upload](/static/SitonCloud/images/xftp/xftp_06.png)

+ 3.文件传输：

&ensp;&ensp;在右边的Linux中右键点击传输，hello.world文件就会传输到Windows的桌面上；同样，在Windows中点击传输也可以传输到Linux的当前文件夹下

![wangpan-upload](/static/SitonCloud/images/xftp/xftp_07.png)

+ 4.更改字符编码：

&ensp;&ensp;当远程连接出现乱码时可以通过更改字符编码解决

![wangpan-upload](/static/SitonCloud/images/xftp/xftp_08.png)
