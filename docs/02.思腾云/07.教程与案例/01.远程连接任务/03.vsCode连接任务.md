## 简介

&ensp;&ensp;VSCode（全称：Visual Studio Code）是一款由微软开发且跨平台的免费源代码编辑器。该软件支持语法高亮、代码自动补全（又称 IntelliSense）、代码重构、查看定义功能，并且内置了命令行工具和 Git 版本控制系统。用户可以更改主题和键盘快捷方式实现个性化设置，也可以通过内置的扩展程序商店安装扩展以拓展软件功能。

## 安装扩展

&emsp;&emsp;在VScode`扩展`中搜索`Remote-SSH`，找到后点击`install`，
::: warning 
  + 未安装的会出现`install`按钮，已安装过的不会在出现
:::

![wangpan-upload](/static/SitonCloud/images/vscode/install_remote-ssh.png)

## 添加远程连接主机

+ 点击`Remote-SSH`图标，点击`新建远程`图标

![wangpan-upload](/static/SitonCloud/images/vscode/vscode_add_task_01.png)

+ 在`思腾云-AI训练中心-我的任务`中，选择`SSH`的`登录命令`，点击`复制`。

![wangpan-upload](/static/SitonCloud/images/my_task_ssh_copy.png)

+ 在`VSCode`中，粘贴复制的`SSH`的`登录命令`。

![wangpan-upload](/static/SitonCloud/images/vscode/vscode_add_task_02.png)

+ 添加远程主机信息会保存在本地配置文件中，选择第1个配置文件即可完成添加。

![wangpan-upload](/static/SitonCloud/images/vscode/vscode_add_task_conf.png)


## 连接远程主机
+ 添加完成后在  `远程资源管理器`中显示刚添加的远程主机。点击`箭头`会在当前窗口打开链接。

![wangpan-upload](/static/SitonCloud/images/vscode/vscode_add_task_03.png)

+ 提示输入密码，在`思腾云-AI训练中心-我的任务`中，选择`SSH`的`密码`，点击`复制`。粘贴到`VSCode`中

![wangpan-upload](/static/SitonCloud/images/vscode/vscode_add_task_04.png)

+ 成功连接后点击`资源管理器`标签会显示已连接到远程。同时左下角提示已连接的`远程主机名称`。

![wangpan-upload](/static/SitonCloud/images/vscode/vscode_add_task_05.png)
