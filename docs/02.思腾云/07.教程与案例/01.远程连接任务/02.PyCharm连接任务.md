## 简介

&ensp;&ensp;PyCharm 是 JetBrains 开发的一款 Python 跨平台编辑器。PyCharm 分为商业化的 **Professional** 版本和免费的 **Community** 版本。**注意只有 Professional 版本才支持远程开发功能**，从菜单中的 Help - About 可以查看当前安装的版本。

::: warning 
+ 本次介绍使用的PyCharm版本为：`PyCharm 2022.3.1 (Professional Edition)`，各版本之间可能会存在部分差异。
:::

## 1. 配置Pycharm远程连接到任务

+  1.在菜单中打开 `Tools -> Deployment -> Configuration`。

![WechatIMG609](/static/SitonCloud/images/pycharm/WechatIMG609.png)

+ 2.点击添加按钮，选择`SFTP`

![WechatIMG611](/static/SitonCloud/images//pycharm/WechatIMG611.png)

+ 3.填写一个远程连接的名字，可自定义，然后点击OK

![WechatIMG612](/static/SitonCloud/images/pycharm/WechatIMG612.png)

+ 4.点击浏览`SSH configuration`的按钮。

![WechatIMG613](/static/SitonCloud/images/pycharm/WechatIMG613.png)

+ 5.点击`+`号，新建一个 SSH 配置。

![WechatIMG614](/static/SitonCloud/images/pycharm/WechatIMG614.png)

+ 6.获取任务SSH主机名、任务SSH端口号、任务密码

  + 6.1 打开思腾云控制台，复制登录指令和密码，然后粘贴到文本或编辑器中。

![WechatIMG615](/static/SitonCloud/images/pycharm/WechatIMG615.png)

  + 6.2 粘贴完成后如下所示

      + 登录指令：ssh -p 54717 root@219.150.35.115

      + 密码：8e7aBcV2V2 

      + 命令解析：
  
|   SSH地址   |   SSH端口号   |  SSH用户    |   SSH密码   |
| ---- | ---- | ---- | ---- |
|  219.150.35.115    |    54717  |   root   |   8e7aBcV2V2    |


+ 7.将获取到的任务信息填入下面，然后点击 `Test Connection`按钮测试连接

![WechatIMG616](/static/SitonCloud/images/pycharm/WechatIMG616.png)

![WechatIMG617](/static/SitonCloud/images/pycharm/WechatIMG617.png)

+ 9.点击Apply应用配置，然后点击OK保存远程连接配置

![WechatIMG618](/static/SitonCloud/images/pycharm/WechatIMG618.png)

+ 10.选中刚才配置的主机，然后再次进行 Test Connection 按钮测试连接

![WechatIMG620](/static/SitonCloud/images/pycharm/WechatIMG620.png)

![WechatIMG621](/static/SitonCloud/images/pycharm/WechatIMG621.png)

完成以上操作后，就已经配置完成了Pycharm连接任务了。

+ 11.可以通过Pycharm中的Terminal来连接任务(可选)

![WechatIMG622](/static/SitonCloud/images/pycharm/WechatIMG622.png)

点击后即可连接到任务

![WechatIMG623](/static/SitonCloud/images/pycharm/WechatIMG623.png)
