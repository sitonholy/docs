::: warning 温馨提示

+ 安装前请检查任务中是否可以`访问互联网`
+ 安装前请检查任务中是否存在`python`与`pip`命令

:::

## 安装

```shell
# 安装Tensorboard
pip install install tensorboard -i https://mirrors.aliyun.com/pypi/simple
```

## 启动

```shell
# 使用Supervisorctl启动Tensorboard服务
supervisorctl start tensorboard
```
