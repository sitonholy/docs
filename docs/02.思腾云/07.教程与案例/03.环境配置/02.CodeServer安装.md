## 下载

+ 官方github地址：[https://github.com/coder/code-server](https://github.com/coder/code-server)
+ Releases地址:[https://github.com/coder/code-server/releases](https://github.com/coder/code-server/releases)

```shell
# 下载
curl -L https://github.com/coder/code-server/releases/download/v4.22.1/code-server_4.22.1_amd64.deb -o /tmp/code-server_4.22.1_amd64.deb 
```

## 安装

```shell
cd /tmp
# 安装CodeServer，注意code-server_4.22.1_amd64.deb名称可能会变化
dpkg -i code-server_4.22.1_amd64.deb
```

## 启动

```shell
# 使用Supervisorctl启动CodeServer服务
supervisorctl start code-server
```
