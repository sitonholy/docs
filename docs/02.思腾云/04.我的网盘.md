&emsp;&emsp;为用户提供了方便的文件管理功能，用户可以很方便的通过平台访问文件，我的网盘主要有以下功能：

+ 上传文件
+ 扩容空间
+ 下载文件
+ 删除文件

::: warning  温馨提示
  + 首次使用需要点击`初始化`。
  + 重要的数据请定期备份到本地，思腾云对于此类存储产品不提供可靠性承诺与服务。
  + 您可以在思腾云租用的任意的任务中访问网盘中的数据，共享存储：`/root/siton-data-*`，对象存储: `/root/siton-object-*`，在`/root/siton-data-*`、`/root/siton-object-*`目录下的操作等同于直接对网盘操作。
  + 若需要上传/下载多个文件，可先打包一个压缩文件再上传。
:::
## 初始化

+ 在控制台界面下点击去存储中心
![wangpan-download](/static/SitonCloud/images/yunpan/yunpan_01.png)

+ 在存储中心中点击对象存储，然后点击新建存储卷
![wangpan-download](/static/SitonCloud/images/yunpan/yunpan_02.png)

+ 新建好后可以通过点击存储桶进入网盘
![wangpan-download](/static/SitonCloud/images/yunpan/yunpan_03.png)

## 上传、下载数据

::: warning  温馨提示
 + 页面上传大文件时可能会失败，上传文件建议使用`sftp`功能进行上传，具体参考[xftp](/pages/a02023/)使用教程。
:::
  
&emsp;&emsp;在网盘空间部分点击上传文件按钮，会弹出文件上传页面，可以点击选择档案或者将文件拖拽到文件上传页面，然后点击确定。

&emsp;&emsp;在我的网盘主界面，点击当前行文件的下载按钮，即可下载对应的文件。
![wangpan-download](/static/SitonCloud/images/wangpan-download.png)

&emsp;&emsp;在我的网盘主界面，点击当前行文件的删除按钮后弹出提示，点击确认，即可删除当前文件。
![wangpan-delete](/static/SitonCloud/images/wangpan-delete.png)

## 网盘扩容

&emsp;&emsp;在网盘空间部分点击扩容按钮，会弹出扩容表单，根据需求填写表单相关信息：扩容大小、扩容时长。点击确定，即可完成扩容。
![register](/static/SitonCloud/images/kuorong_file.png)
